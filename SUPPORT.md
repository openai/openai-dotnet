# Support

## Getting help

### GitHub issues

Use [GitHub Issues](https://github.com/openai/openai-dotnet/issues/new/choose)
to report bugs, ask questions about the OpenAI .NET library, or suggest
features. Search [existing issues](https://github.com/openai/openai-dotnet/issues)
before filing a new one. GitHub issues are free, but response times are not
guaranteed.

For a bug report, include the package version, .NET version, operating system,
steps to reproduce, and a minimal example without credentials or sensitive
data. Confirm that the issue reproduces with the latest package against the
official OpenAI service.

For help with the OpenAI API or account rather than the .NET library, contact
[OpenAI Support](https://help.openai.com/).

### Security issues

Do not report security vulnerabilities through public issues. Follow the
private reporting instructions in [SECURITY.md](./SECURITY.md).

## Support policy

The OpenAI .NET library supports only the latest
[`OpenAI` package](https://www.nuget.org/packages/OpenAI). Issues found with
earlier versions must be reproducible with the latest package before we can
investigate them.

The OpenAI client library offers support only for the official OpenAI service.
While we do not discourage use with other services and models, we are unable
to offer support for them. In order to assist, we need to understand how to
reproduce the reported behavior with the official OpenAI service.

Supported .NET runtimes that implement .NET Standard 2.0 are eligible for
support. Compatibility with runtimes or dependencies that have reached end of
life is not guaranteed.
